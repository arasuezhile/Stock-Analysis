Summary of Changes: AnalysisEngine (Fibonacci Update)
This version introduces Fibonacci Retracement analysis and applies it to both long-term and short-term charts for a more comprehensive view.

1. New Core Feature: Fibonacci Level Calculation

New Method Added: calculate_fibonacci_levels()
Purpose: To automatically calculate key potential support and resistance levels based on the Fibonacci sequence.
Logic: The function finds the absolute highest high and lowest low over the given data period. It then calculates the standard retracement levels (23.6%, 38.2%, 50%, 61.8%, and 78.6%) based on this price range.
Output: It stores a list of these price levels, ready to be plotted.
2. Enhancements to Existing Functionality

Plotting Function Updated: plot_analysis()

A new boolean parameter, show_fib, was added to control the visibility of the Fibonacci levels on the chart.
When show_fib=True, the function now draws the calculated Fibonacci levels as horizontal, colored, dotted lines, with each line labeled by its percentage.
Test Script Enhanced for Deeper Analysis

The main test block at the bottom of the script was updated to call calculate_fibonacci_levels() for both the long-term (5-year) and short-term (1-year) analysis.
The plot_analysis() function is now called with show_fib=True for both timeframes, ensuring that each chart displays its own relevant Fibonacci levels. This provides a richer analytical view on both the "big picture" and the immediate price action.
