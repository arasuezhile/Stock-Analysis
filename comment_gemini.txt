Summary of Changes: ML Feature Generation Module
This update introduces the first major component of the Machine Learning pipeline, fulfilling Stage 3 (Feature Engineering) of the ML architecture.

1. New Module Created: feature_generator.py

A new, self-contained script has been created to handle the transformation of raw price data into a feature-rich dataset suitable for model training.
It introduces the FeatureGenerator class, which orchestrates the entire process.
2. Generation of Key Features

The script systematically calculates and adds the following features for each trading day in the historical data:

Technical Indicators (Calculated Manually): To ensure maximum stability and avoid the library conflicts we previously faced, the following indicators are now calculated directly using pandas functions:

RSI (14): Relative Strength Index (14-period).
MACD: Moving Average Convergence Divergence with its signal line and histogram (MACD_12_26_9, MACDs_12_26_9, MACDh_12_26_9).
Bollinger Bands (20, 2): The middle band, upper band, and lower band.
Price and Volatility Features:

price_change_1d & price_change_5d: The percentage change in closing price over the last 1 and 5 days.
volatility_21d: The 21-day rolling standard deviation of daily returns, a measure of recent price volatility.
3. Output and Preparation for ML

CSV Output: The script's primary output is a CSV file (e.g., RELIANCE.NS_features.csv) containing the full dataset with all the generated features. This file serves as the foundational dataset for our ML model.
Placeholder Label: A label column is intentionally added to the final CSV. This prepares the dataset for the next crucial phase: Data Labeling, where we will assign a "correct" outcome to each day for supervised learning.
4. Dependency Management

The problematic pandas-ta library and other unnecessary dependencies have been removed from requirements.txt, making the project more robust and less prone to environment conflicts.
